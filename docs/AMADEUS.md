## 音源补齐后完成

目前没有用户提供的歌曲 WAV 与 LRC／歌词文件；**正式 `out/amadeus_1080p60.mp4` 尚未生成，音画同步未验收**。全片检查版使用已有节拍特征和明确标记的占位文字，不能作为正式歌词 MV。

1. 按 `config.json → paths.audio / paths.lrc` 放入用户提供的原曲和歌词，再运行 `npm run lyrics`。默认沿用原曲语言及已有分行与时间轴。
2. 若音源开头留白不同，先检查波形及提示点，校正 `timing.offset`；若剪辑或速度不同，重新分析并调整时间轴。
3. 重新生成真实歌词联系表，检查文字换行、字号、字母卡点及所有关键镜头。
4. 运行 `npm run export:preview` 输出 1920×1080／60fps 的正式成片，并运行音画同步、一般／红色闪光、单帧突跳和亮度检查；有异常先修复光效再导出复测。
5. 将实际测量结果补入本文件，完成封面、角色素材、提示词、可运行工程与正式 MP4 的最终交付。
