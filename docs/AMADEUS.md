## 本轮完成

- 保留原工程歌曲时间轴、节拍和 87 个镜头，含歌曲前 5 秒警告页；所有 129 行均有对应镜头。

- 长发、白衬衫、红领带及落肩外套建立红莉栖辨识度。前段面部保持留白，空线程段首次露眼；猫耳为短暂玩笑形态。F／M 更新档案字段并扫描，回忆循环将同一人物的三层墨版拆开重组，不再加载少年和成年男性素材。

- Canvas 重绘参考图的 Amadeus 线稿标志及十二段记忆环用于标志、加载、思考和转场。聊天、历史、设置、身份卡、错误和关机统一为 Amadeus／记忆档案／连接主题，对方保持匿名。错误循环保留十二次执行及数数结构：保存的记忆不能代替对方的在线状态或回应。

- macOS 导出使用 Chrome 的 Metal 渲染。Python 检查入口支持 macOS／Windows，可用 `MV_PYTHON` 选择环境。正常导出遇到缺歌词／音源时停止；占位检查视频必须显式使用 `--layout-only --silent`，并始终显示预览标记。

## 标志线稿修订

用户要求移除普通 A，按第二张标志参考图绘制线稿。`assets/amadeus/logo-reference.png` 保存该参考；`mark-full.svg` 与 `mark-compact.svg` 和 Canvas 使用同一组手绘矢量路径，保留斜三角、内部折线、横向字标与下方尖角，内部透明，无参考图的纹理或背景。

名义半径达到 64 使用完整字标，其余使用简化徽记；简化版省略文字并保留斜三角和折线。外环旋转，徽记直立。`grow` 只缩放已选版本；从小头像放大到全屏的思考镜头显式固定完整版，避免中途换形。`core: 0` 仍为纯外环。共享组件覆盖启动、聊天空态、侧栏、消息、设置、思考、错误、版画和关机。

## 音源补齐后完成

目前没有用户提供的歌曲 WAV 与 LRC／歌词文件；**正式 `out/amadeus_1080p60.mp4` 尚未生成，音画同步未验收**。全片检查版使用已有节拍特征和明确标记的占位文字，不能作为正式歌词 MV。

1. 按 `config.json → paths.audio / paths.lrc` 放入用户提供的原曲和歌词，再运行 `npm run lyrics`。默认沿用原曲语言及已有分行与时间轴。
2. 若音源开头留白不同，先检查波形及提示点，校正 `timing.offset`；若剪辑或速度不同，重新分析并调整时间轴。
3. 重新生成真实歌词联系表，检查文字换行、字号、字母卡点及所有关键镜头。
4. 运行 `npm run export:preview` 输出 1920×1080／60fps 的正式成片，并运行音画同步、一般／红色闪光、单帧突跳和亮度检查；有异常先修复光效再导出复测。
5. 将实际测量结果补入本文件，完成封面、角色素材、提示词、可运行工程与正式 MP4 的最终交付。
